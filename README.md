# 🚀 3D Portfolio Website

An immersive futuristic 3D portfolio website built with modern web technologies, smooth animations, cinematic UI/UX, and interactive experiences inspired by award-winning Awwwards and WebGL websites.

---

## 🌌 Overview

This project is a premium personal portfolio website designed to showcase creativity, projects, skills, and developer expertise through immersive 3D interactions, smooth transitions, and modern storytelling UI.

The website combines minimal aesthetics with futuristic motion design to create a highly engaging user experience.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/3d-portfolio.git
```

Move into the project folder:

```bash
cd 3d-portfolio
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

---

# 📦 Build

```bash
npm run build
```
